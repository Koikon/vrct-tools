# Gaming & VRChat

Gamer jargon and VR/VRChat vocabulary you'll hear in Chinese voice chat. Praise codes like 666 / GG are in [[Number & Letter Codes]]; ways of addressing people are in [[People & Address]].

| Chinese | Pinyin | Literal | Natural English | Notes |
|---|---|---|---|---|
| 大佬 | dàlǎo | big old (boss) | pro / expert / legend | Often half-joking praise. Cantonese origin ("big shot"). |
| 大神 | dàshén | great god | god-tier player / pro | Similar to 大佬. |
| 萌新 | méngxīn | cute new | newbie / new player | Self-deprecating, friendly. Joke: 大佬装萌新 (smurfing pro). |
| 小白 | xiǎobái | little white | total beginner / noob | Neutral, not insulting. |
| 菜 / 太菜了 | cài | vegetable | bad (at the game) / I suck | 我好菜 = "I'm so bad". MT: "vegetable / dish". |
| 菜鸡 / 菜鸟 | càijī / càiniǎo | vegetable chicken/bird | noob | Playful insult. Trad. 菜雞 / 菜鳥. |
| 坑 / 坑货 | kēng | pit | liability / trolling teammate | 坑我 = "screwed me over". |
| 猪队友 | zhū duìyǒu | pig teammate | useless teammate | Rude-ish. Trad. 豬隊友. |
| 带我 / 带飞 | dài wǒ / dài fēi | bring me / carry-fly | carry me / carry (the team) | 求带 = "please carry me / show me around". Trad. 帶我 / 帶飛. |
| 躺赢 | tǎng yíng | lie down win | got carried / easy win | Trad. 躺贏. |
| 开黑 | kāi hēi | open black | play together (in a party with voice) | MT: "open black". Trad. 開黑. |
| 挂机 | guà jī | hang machine | AFK / idle | Trad. 掛機. In VRC often = asleep/AFK in world. |
| 掉线 | diào xiàn | drop line | disconnected / DC'd | Trad. 掉線. |
| 卡了 / 好卡 | kǎ le | stuck | lagging / frozen | Trad. same. MT: "card / stuck". |
| 延迟 | yánchí | delay | ping / latency | Trad. 延遲. 高延迟 = high ping. |
| 掉帧 | diào zhēn | drop frame | frame drops / low FPS | Trad. 掉幀. |
| 麦 | mài | mic (from 麦克风) | mic | MT: "wheat" (麦 = wheat!). Trad. 麥. |
| 开麦 / 闭麦 | kāi mài / bì mài | open/close mic | unmute / mute (yourself) | 你没开麦 = "you're muted". Trad. 開麥 / 閉麥. |
| 静音 | jìngyīn | quiet sound | mute | Trad. 靜音. |
| 模型 | móxíng | model | avatar | Most common VRC word for avatar. |
| 皮 / 皮肤 | pí / pífū | skin | skin / avatar look | Trad. 皮膚. |
| 虚拟形象 | xūnǐ xíngxiàng | virtual image | avatar | Official VRChat Chinese term. Trad. 虛擬形象. |
| 世界 / 地图 | shìjiè / dìtú | world / map | world (VRC instance map) | 换个世界 = "let's switch worlds". Trad. 地圖. |
| 房间 / 房 | fángjiān | room | instance / lobby | 进房 = join the instance. Trad. 房間. |
| 好友 | hǎoyǒu | good friend | friend (friend list) | 加好友 = "add (me as) friend". |
| 拉黑 | lā hēi | pull black | block | Trad. same. |
| 屏蔽 | píngbì | screen off | block / hide (avatar, voice) | Trad. same. |
| 头显 | tóuxiǎn | head display | VR headset / HMD | Trad. 頭顯. |
| 全身追踪 / 全身 | quánshēn zhuīzōng | whole-body tracking | full-body tracking (FBT) | Trad. 全身追蹤. |
| 桌面 | zhuōmiàn | desktop | desktop (non-VR) player | |
| 手柄 | shǒubǐng | hand handle | controller | |
| 二次元 | èrcìyuán | 2nd dimension | anime/ACG fan culture / anime-style | 二次元的 = "anime (style)". |
| 老婆 | lǎopó | wife | waifu / my (anime) girl | For anime characters or cute avatars, not literal. |
| 老公 | lǎogōng | husband | husbando | Same idea, for male characters. |
| 肝 | gān | liver | grind (hard) | 肝游戏 = grinding the game. MT: "liver". |
| 氪金 | kè jīn | krypton gold | pay-to-win / spend real money | Trad. same. |
| 寄了 | jì le | mailed | it's over / we're dead | See [[Internet Slang]]. |
| 白给 | bái gěi | give free | throwing / free kill | Trad. 白給. |
| 毒奶 | dú nǎi | poison milk | jinx | Saying "we'll win" then losing. |
| 老六 | lǎo liù | old six | sneaky camper / troll player | Also "useless teammate". Meaning varies. |
| 吃鸡 | chī jī | eat chicken | win (battle royale) / play PUBG | Trad. 吃雞. |
