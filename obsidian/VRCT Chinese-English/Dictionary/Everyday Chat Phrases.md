# Everyday Chat Phrases

Ordinary conversational filler that MT often renders stiffly or wrongly (e.g. 吃了吗 → "Have you eaten?" when it just means "hey"). Slang is in [[Internet Slang]]; codes like 88 / 233 in [[Number & Letter Codes]].

| Chinese | Pinyin | Literal | Natural English | Notes |
|---|---|---|---|---|
| 你好 | nǐ hǎo | you good | hi / hello | A bit formal among friends. |
| 哈喽 / 嗨 | hālóu / hāi | (hello / hi) | hey! / hi | Casual loanwords. Trad. 哈囉. |
| 在吗 | zài ma | are (you) here? | you there? / hey | Opener before a message. Trad. 在嗎. |
| 干嘛呢 | gàn má ne | doing what | what are you up to? / wyd | Trad. 幹嘛呢. |
| 吃了吗 | chī le ma | eaten yet? | hey, how's it going? | Greeting, not a real question about food. Trad. 吃了嗎. |
| 没事 | méi shì | no matter | it's fine / no worries / nothing | Trad. 沒事. |
| 没关系 | méi guānxi | no relation | that's okay / no problem | Reply to an apology. MT: "no relationship". Trad. 沒關係. |
| 不客气 | bú kèqi | don't be a guest | you're welcome | Trad. 不客氣. |
| 谢谢 / 谢啦 | xièxie / xiè la | thanks | thanks / thx | Trad. 謝謝. |
| 等一下 / 等等 | děng yíxià | wait a bit | hold on / one sec | |
| 马上 | mǎshàng | on horseback | right away / coming! | MT: "on horseback". Trad. 馬上. |
| 走了 | zǒu le | walked | I'm heading out / gotta go | Also "let's go". |
| 拜拜 / 88 | bái bái | bye-bye | bye! | See [[Number & Letter Codes]]. |
| 回头见 | huítóu jiàn | turn-head see | see you later | Trad. 回頭見. |
| 晚安 | wǎn'ān | night peace | good night | |
| 真的假的 | zhēn de jiǎ de | real or fake | seriously? / no way! / for real? | MT: "real fake". |
| 对啊 / 是啊 | duì a / shì a | right / yes | yeah / exactly / right? | Trad. 對啊. |
| 嗯嗯 | ǹg ǹg | hm-hm | yeah / ok / mm-hm | Softer/cuter than single 嗯. |
| 哦哦 | ó ó / ò ò | oh oh | oh, I see / ahh okay | Understanding. |
| 哦 (single) | ò | oh | oh. / k. | Can sound curt/cold in text. |
| 还行 | hái xíng | still ok | not bad / it's alright | Trad. 還行. |
| 随便 | suíbiàn | as you like | whatever / up to you | Can sound dismissive. Trad. 隨便. |
| 算了 | suàn le | counted | never mind / forget it | |
| 加油 | jiā yóu | add oil | you got this! / go! | MT: "add oil / refuel". |
| 辛苦了 | xīnkǔ le | (you) suffered | thanks for your hard work / good job | Appreciation, not pity. |
| 哈哈哈 / hhh | hā hā hā | haha | hahaha / lol | hhh = lazy typing of 哈哈哈. |
| 呵呵 | hē hē | heh heh | heh. (sarcastic) | Often read as passive-aggressive/dismissive. |
| 嘻嘻 | xī xī | hee hee | hehe (cheeky) | |
| 好的 / 好吧 | hǎo de / hǎo ba | good | okay / alright (fine) | 好吧 = reluctant "fine". |
| 没问题 | méi wèntí | no problem | no problem / sure | Trad. 沒問題. |
| 不好意思 | bù hǎo yìsi | not good meaning | sorry / excuse me | Light apology. MT: "not good meaning". |
| 对不起 | duìbuqǐ | can't face | I'm sorry | Stronger apology. Trad. 對不起. |
| 我也是 | wǒ yě shì | I also am | me too / same | |
| 厉害 | lìhai | fierce | impressive! / wow | Trad. 厲害. |
| 听不清 / 听不到 | tīng bu qīng / dào | hear not clear | can't hear you (clearly) | Common in VR voice chat. Trad. 聽不清. |
| 你说什么 | nǐ shuō shénme | you say what | what did you say? / sorry? | Trad. 你說什麼. |
| 么么哒 | me me da | (kiss sound) | mwah~ / xoxo | Cute. Trad. 麼麼噠. |
| 也是醉了 | yě shì zuì le | also drunk | I can't even / are you kidding | Exasperated. |
| 回聊 | huí liáo | back chat | ttyl | |
