# People & Address

How people call each other in chat. Family words (brother, sister, wife) are usually *not* literal — MT will make it sound like everyone is related. See also [[Gaming & VRChat]] (大佬, 萌新, 老婆) and [[Everyday Chat Phrases]].

| Chinese | Pinyin | Literal | Natural English | Notes |
|---|---|---|---|---|
| 老铁 | lǎotiě | old iron | bro / buddy / fam | Northeastern origin, spread via livestreams. Any gender. Trad. 老鐵. MT: "old iron". |
| 兄弟 | xiōngdì | brothers | bro / dude | Casual. |
| 兄dei / 兄嘚 | xiōng dei | (lazy 兄弟) | bruh / bro | Northeastern-accent spelling, jokey. |
| 哥们 / 哥们儿 | gēmen(r) | brothers | buddy / pal | Trad. 哥們. |
| 家人们 | jiārénmen | family members | fam / everyone / y'all | Livestream-style address to audience. Trad. 家人們. |
| 宝 / 宝宝 / 宝子 | bǎo / bǎobao / bǎozi | treasure / baby | babe / hun / sweetie | Affectionate; 宝子 = livestream "darling". Not necessarily romantic. Trad. 寶. |
| 亲 / 亲爱的 | qīn / qīn'ài de | dear | dear / hun | 亲 = Taobao-seller politeness. Trad. 親. |
| 小姐姐 | xiǎo jiějie | little big-sister | (that) girl / miss / cute girl | Friendly/polite address to a young woman. Not a sibling. |
| 小哥哥 | xiǎo gēge | little big-brother | (that) guy / cute guy | Male counterpart. |
| 小哥 | xiǎo gē | little brother | young man / dude | Friendly for a young man. |
| 大哥 | dàgē | big brother | bro / boss / man | Respectful-casual to an (older) man; also "the big man". |
| 大姐 | dàjiě | big sister | ma'am / sis | Older woman. |
| 姐妹 / 集美 | jiěmèi / jíměi | sisters | girl / bestie / sis | 集美 is the internet pun spelling. Used among women. |
| 闺蜜 | guīmì | boudoir honey | BFF (female) | Trad. 閨蜜. |
| 基友 | jīyǒu | "gay" friend | bro / best (male) friend | Playful innuendo. |
| 死党 | sǐdǎng | death party | ride-or-die friend | Trad. 死黨. |
| 同志 | tóngzhì | comrade | comrade (political) / gay person | **Modern:** mostly means gay/LGBT in casual talk; comrade only in official speech. Taiwan/HK: LGBT sense. |
| 老板 | lǎobǎn | boss | boss / (shop) owner / big spender | Also flattering address, and "patron" who tips streamers. Trad. 老闆. |
| 老师 | lǎoshī | teacher | (respected) master / pro | Used for artists/creators, not literal teachers. Trad. 老師. |
| 师傅 | shīfu | master | driver / worker (polite) | Trad. 師傅. |
| 同学 | tóngxué | classmate | hey (to young people) | Trad. 同學. |
| 美女 / 帅哥 | měinǚ / shuàigē | beautiful woman / handsome guy | miss / hey handsome | Generic polite address, not real flattery. Trad. 帥哥. |
| 小伙子 / 姑娘 | xiǎohuǒzi / gūniang | young fellow / girl | young man / young lady | Older speakers. |
| 妹子 | mèizi | little sister | girl / gal | Casual. |
| 大叔 / 阿姨 | dàshū / āyí | uncle / auntie | older guy / older lady | Also for strangers. |
| 老乡 | lǎoxiāng | old hometown | fellow countryman / homie | Same hometown/region. Trad. 老鄉. |
| MM / GG | — | (妹妹 / 哥哥) | girl / guy | Old pinyin abbreviations. See [[Number & Letter Codes]]. |
| 舔狗 | tiǎn gǒu | licking dog | simp | Derogatory. |
| 海王 | hǎi wáng | sea king | player / playboy | Dates many at once. |
